I take long-term ownership of product software.

UK-based independent senior developer. I have been developing since 2007 and contracting remotely since 2014. I work across backend and frontend, databases, infrastructure, automated testing and CI/CD.

The attribute I trust most is that I enjoy learning. That is not a slogan. It is how I do the job: sit with the system you already have, learn how people actually use it, and turn that understanding into a small change worth shipping.

How I work

I talk directly with stakeholders. I would rather ask a precise question than build the wrong thing. Needs get translated into small, deliverable changes — modernising what exists, not starting from a blank page because a new stack is fashionable.

  • Adapt tools to the problem. I do not chase trends for their own sake.
  • Test actual behaviour, not only the path that happens to be easy to script.
  • Preserve existing data. It is part of the product.
  • Communicate clearly and stay with the work as a reliable ongoing owner.
  • Engineer with cost in mind: understand what the system needs, and avoid running more cloud than that.

Strengths

  • Long-term end-to-end product ownership, from a conversation through to a tested change.
  • Backend and frontend together.
  • Databases, infrastructure, automated testing and CI/CD.
  • Authentication and identity integration.
  • Modernising systems people already depend on, including making them cheaper to run where the waste is real.

Technologies

Coding with agents

I use Cursor and other coding agents as part of ordinary engineering: a clear brief, a task breakdown, a review, and verification of real user flows. They are useful on well-specified work. I remain responsible for architecture, correctness and maintainability. I do not treat generated code as finished because it compiles, and I do not claim agents make delivery magically faster.
